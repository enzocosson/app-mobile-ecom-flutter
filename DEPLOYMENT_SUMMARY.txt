🔑 SECRETS GITHUB REQUIS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Configurer dans : GitHub Repository → Settings → Secrets and variables → Actions

┌─────────────────────┬──────────────────────────────────────────────┐
│ Nom du Secret       │ Comment l'obtenir                            │
├─────────────────────┼──────────────────────────────────────────────┤
│ VERCEL_TOKEN        │ https://vercel.com/account/tokens            │
│                     │ → Create Token → Full Account                │
├─────────────────────┼──────────────────────────────────────────────┤
│ VERCEL_ORG_ID       │ Exécuter: ./setup_vercel.sh                  │
│                     │ ou: cat .vercel/project.json → orgId         │
├─────────────────────┼──────────────────────────────────────────────┤
│ VERCEL_PROJECT_ID   │ Exécuter: ./setup_vercel.sh                  │
│                     │ ou: cat .vercel/project.json → projectId     │
└─────────────────────┴──────────────────────────────────────────────┘


⚡ COMMANDES RAPIDES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔧 Configuration Initiale
────────────────────────────────────────────────────────────────────
./setup_vercel.sh                 # Configuration automatique guidée
npm install -g vercel             # Installer Vercel CLI manuellement
vercel login                      # Se connecter à Vercel
vercel link                       # Lier le projet


🧪 Tests Locaux
────────────────────────────────────────────────────────────────────
./pre_deploy.sh                   # Vérifier tout avant de pusher
flutter clean && flutter pub get  # Nettoyer et installer dépendances
flutter build web --release       # Build Web
vercel deploy build/web           # Test déploiement manuel (preview)
vercel deploy build/web --prod    # Test déploiement manuel (production)


📤 Déploiement Preview (Pull Request)
────────────────────────────────────────────────────────────────────
git checkout -b feature/my-feature
git add .
git commit -m "Add new feature"
git push origin feature/my-feature
# → Créer une PR sur GitHub
# → Preview deployment automatique (3-5 min)
# → URL de preview commentée sur la PR


📤 Déploiement Production
────────────────────────────────────────────────────────────────────
git checkout main
git merge develop                 # ou merger la PR
git push origin main
# → Production deployment automatique (3-5 min)
# → App live sur https://your-project.vercel.app

📊 JOBS GITHUB ACTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

├────────────────────┼───────────┼──────────────────────────────┤

│ build-web          │ ~2 min    │ Tous les push/PR             │

🎯 ÉTAPES SUIVANTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  CONFIGURATION VERCEL
   ./setup_vercel.sh
   → Suit le guide interactif

2️⃣  AJOUTER LES SECRETS GITHUB
   → GitHub Repository → Settings → Secrets and variables → Actions
   → Ajouter VERCEL_TOKEN, VERCEL_ORG_ID, VERCEL_PROJECT_ID

3️⃣  TESTER PREVIEW DEPLOYMENT
   git checkout -b test/deployment
   git add .
   git commit -m "Test: Preview deployment"
   git push origin test/deployment
   → Créer une PR
   → Attendre 3-5 minutes
   → Vérifier l'URL de preview

4️⃣  TESTER PRODUCTION DEPLOYMENT
   git checkout main
   git merge test/deployment
   git push origin main
   → Attendre 3-5 minutes
   → Vérifier l'app sur l'URL de production

5️⃣  CONFIGURER DOMAINE PERSONNALISÉ (Optionnel)
   → Vercel Dashboard → Project → Settings → Domains
   → Ajouter votre domaine


⚠️  IMPORTANT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ NE PAS commiter :
   - .vercel/project.json (déjà dans .gitignore)
   - .vercel.env (créé par setup_vercel.sh)
   - Tokens/secrets

✅ TOUJOURS vérifier :
   - Noms des secrets EXACTEMENT comme indiqué (majuscules)
   - Tests passent en local avant de pusher (./pre_deploy.sh)
   - Build Web réussit localement
